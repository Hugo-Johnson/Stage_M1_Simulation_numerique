# READ ME STAGE INRIA

## Stage M1 — Simulation de systèmes Hamiltoniens
### Émission cyclotron

3 juin – 17 juillet 2025, Montpellier
Encadré par Dr. Hélène Mathis et Dr. Benoit Jouault, avec l'aide de Frédéric Teppe

Un rapport est présent sur cette page et explique la première approche réalisée lors du stage, ainsi que le code final rendu à l'issue du stage.

On retrouve aussi plusieurs notebooks, représentant chacun un système Hamiltonien différent à étudier. Le premier étant le cas "Jouet", qui est le problème le plus trivial et permet de comprendre les enjeux du stage.

Un code "streaming_example" permet aussi de simuler la trajectoire des particules selon les bandes choisies. Le PDF "Explicit symplectic approximation..." permet de comprendre la méthode d'intégration utilisée dans ce code.

Les librairies classiques sont utilisées, à part PyHamSys qui devra sûrement être installée et qui regroupe des méthodes liées à la résolution de systèmes Hamiltoniens.
